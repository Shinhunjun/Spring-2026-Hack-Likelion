## Metadata

```python
## Dataset Metadata (demographics.csv)

Each row corresponds to a single PSG session (visit) for a patient. 

The file contains the following fields:

- SiteID  
  Identifier of the data collection site (hospital or research center) where the sleep study was conducted.

- BDSPPatientID
  Unique patient identifier on the Brain Data Science Platform (BDSP).

- BidsFolder
  Standardized BIDS (Brain Imaging Data Structure) directory name used to link metadata to physiological EDF files.

- SessionID
  Identifier for the specific sleep study session/visit for a patient.
  
- BMI
  Body Mass Index (BMI) extracted from available clinical measurements around the time of the sleep study.

- Time_to_Event *(training set only)*  
  Time (in days) from the PSG recording to the first recorded cognitive impairment diagnosis.  
  Empty if no diagnosis occurred during follow-up.

- Cognitive_Impairment *(training set only)*  
  Binary outcome label indicating whether the patient developed cognitive impairment.  
  - `TRUE`: Patient was diagnosed with cognitive impairment (mild cognitive impairment, Alzheimer’s disease, or dementia),  
    defined as having at least two qualifying ICD-9/ICD-10 codes, with the first diagnosis occurring at least 3 years  
    and no more than 7 years after the PSG, and with at least one week between diagnoses.  
  - `FALSE`: No cognitive impairment diagnosis, with at least 7 years of follow-up data available  
    (at least 6 years for Site I0002).

- Last_Known_Visit_Date *(training set only)*  
  Date of the patient’s most recent clinical follow-up visit.

- Time_to_Last_Visit *(training set only)*  
  Follow-up duration (in days) from the PSG recording to the patient’s last known clinical visit.
```

## Algorithmic Annotations (CAISR Framework)

The dataset provides automated sleep and clinical event annotations generated by **Complete AI Sleep Report (CAISR)**.

# These are **automated predictions**, not human-labeled gold standards.

### Sleep Staging Annotations

```python
1 = N3
2 = N2
3 = N1
4 = REM
5 = Wake
9 = Unavailable

stage_caisr          # Predicted sleep stage (hard label)

caisr_prob_n3        # Softmax probability for N3
caisr_prob_n2        # Softmax probability for N2
caisr_prob_n1        # Softmax probability for N1
caisr_prob_r         # Softmax probability for REM
caisr_prob_w         # Softmax probability for Wake

# Resolution : 30 seconds per epoch
# Based on EEG, EOG, and EMG signals
```

### Arousal Detection

```python
arousal_caisr        # 0 = no arousal, 1 = arousal
caisr_prob_no-ar     # Probability of no arousal
caisr_prob_arous     # Probability of arousal

# Resolution : 0.5~second intervals
```

### Respiratory Event Detection

```python
# Available Channel

```
